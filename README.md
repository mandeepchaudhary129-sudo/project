PROJECT food ordering management system in c programing

1. Project Overview
   
    food ordering management system Project is a lightweight, interactive Food Ordering Management System designed for efficiency and simplicity. It allows users to seamlessly browse a curated menu of 25 food items, search for dishes in real-time, manage an active cart, generate itemized bills (with taxes included), and exit the session cleanly.
   
2. Languages Used

     Frontend: HTML5 (Structure), CSS / Tailwind (Design), JavaScript (Interactivity).
     Backend / Core Logic: C language & JavaScript logic (Handling data processing and calculations).

  4. DSA Concepts Used

     Arrays / Lists: To store the 25 menu items and track quantities.
     Structures / Objects (struct): To group item properties (id, name, price).
     Linear Search: Powers the live search bar to find dishes instantly.
     Hash Mapping / Key-Value Tracking: Manages cart quantities ($Item ID \rightarrow Quantity$) for quick updates.

5. Key Features
   
     25-Item Menu: Covers fast food, snacks, beverages, and meals.
     Live Search: Instant filtering as you type.
     Interactive Cart: Add, view, or remove items easily.
     Bill Generator: Calculates subtotal, tax, and grand total with a print option.
     Session Control: Clean exit and restart workflow
